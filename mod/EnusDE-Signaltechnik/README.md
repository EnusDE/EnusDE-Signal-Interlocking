# EnusDE Signal & Interlocking 0.7.15

For **Railroader 0.6.2**. Install the extracted `EnusDE-Signaltechnik` folder as a Railroader asset pack or use a compatible mod manager. Restart Railroader, enable the mod in the main menu, then open **STW** next to the clock.

Host and clients must use the same version. This is a pre-release. See **AENDERUNGEN.md** for the in-game setup guide in German.

[Project and downloads](https://github.com/EnusDE/EnusDE-Signal-Interlocking)
