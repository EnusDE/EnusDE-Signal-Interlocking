# 0.7.49-P0 — Prepared compatibility test candidate for Railroader 0.6.3

**Not yet built against the original 0.6.3 libraries or tested in game.**
The running workspace still contains the earlier library set. This ZIP is explicitly
an unverified test candidate, not a confirmed 0.6.3 release. The new uploaded libraries
cannot currently be downloaded here because the download tool encounters a read-only
filesystem. The updated environment shown in the screenshot is not present in this
running workspace.

## Changes

- Mod version 0.7.49; exact game dependency `rr/game ==0.6.3`.
- The former direct `Game.UserPaths` reference is resolved at startup. The adapter
  prefers `Game.HomeDirectory.UserPaths`, also supports the nested-type spelling,
  and only falls back to the legacy API when the new API is absent.
- Railroader's returned path is read unchanged. No saves, settings or user data move.
- Unsupported signatures, empty paths and failing getters report errors instead of
  guessing a replacement settings location.
- Includes the editor and number-display changes from 0.7.48/0.7.47.

## Verification status

The full existing suite runs against the earlier libraries actually available here.
Targeted simulated API contracts additionally check the new path variant. These
checks cover the adapter and existing mod logic; they do not replace a build against
the original 0.6.3 DLLs.

Before publication: build against the new Managed libraries, rerun native hook and
signature checks, and complete gameplay/multiplayer acceptance. All participants
require matching mod version 0.7.49.

## Manual candidate testing

Use a backed-up test world on 0.6.3. Enable the mod, load a world, open IXL/STW and
the editor, inspect signal/point/GFM feedback, then set and release a route. When the
optional translation mod is present, also check unit preferences. Inspect logs for
missing types, methods and unsupported hook signatures. Preserve the previous world
installation if any failure occurs.

Older packages, including 0.7.48, remain unchanged. The ZIP contains only the mod's
own assembly and mod files; it redistributes no game libraries.
