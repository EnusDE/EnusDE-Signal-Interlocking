# Settings from the launcher — 0.7.60

Open **IXL / STW** beside the clock, then select the **gear**. It opens a separate, resizable settings window with a scrollable form. The other three symbols still open Dispatcher, Build and Editor.

The gear remains available before construction is unlocked in Milestones, while the layout is loading, and to clients. The launcher also remains visible if an older settings file had disabled the clock button. That former hide-button option is no longer offered, so the settings entrance cannot hide itself.

This completely replaces the mod's former preferences tab and Company → Settings → Mods selector. The game's installed-mod list keeps its native behavior. Other mods' entries are untouched.

Existing values use the same settings file and world configuration. No installation, diagram, object, route or link is migrated or deleted. Select **Apply & Save** to accept edits; closing and reopening the window retains pending edits during the same session. Changing worlds reloads the saved settings into the editor.

English is the default. Choose **Deutsch** in **Interface language** for German without another mod. Local display and diagnosis preferences remain local. Shared construction, economy, automation and operating permissions retain their existing host restrictions. Opening settings does not unlock construction or grant dispatcher rights.

This is an Early Alpha test update for **Railroader 0.6.3**. Host and clients must all use **0.7.60**. Install manually through your mod manager and restart the game completely. Previous 0.7.59 archives are unchanged.

In-game checks: gear before milestone unlock; repeated open/close; apply language changes; client-local settings and host-only restrictions; native Company mod list; world unload/reload. Offline callback tests do not replace these checks.
