# 0.7.24-P0 – short tests in your existing world

Railroader 0.6.2. Replace the mod and restart the game; no new save is required. Host and clients need matching versions. Check the external installation backup before reconstruction. These gameplay checks are still pending.

1. **Master views:** Open STW → Editor and create a new master interlocking. Use Manage to rename and open it. Add a local interlocking as a linked module. Place the same local module elsewhere in another master view; their module positions must remain independent.
2. **Recognition:** Open Automatic recognition from the interlocking selection. Read the network and apply detected sections; existing drawings must remain. Generate a new diagram proposal and inspect its read-only preview. Apply only a complete proposal. The old drawing and its modules must remain in an archive view. Missing items prevent replacement; record the message and affected location.
3. **Removal:** Create an empty test view and remove it through Manage. Removing the default master must promote another master view or create an empty replacement. Read the explicit warning before removing a station with connected open-line definitions.
4. **Settings:** Open Company → Settings → Mods → Signal & Interlocking. Existing settings must be retained. The old preferences page points here. Clients must not gain access to native host mod management.
5. **Points:** With no route locked, throw a configured electric point. Leave waypoint AI stopped at a Stop signal and repeat the reported speed change. The native AI must not throw that electric point back, including with block coordination disabled. Check an ordinary unlocked hand point separately. Native CTC points retain their original rules.
6. **Contact:** Place or click an automation contact before the first main signal. Select the start signal and direction, enable the axle-test display and save. Both the contact and display must open its menu. Automatic requests additionally require the AI signal bridge, contact automation, block coordination, complete configured detection coverage, the locomotive's Train movement role and the start signal's destination automation. After saving, use Configure start-signal automation. Watch passage counts with a short slow train; this is an experimental counter, not reliable train detection.
7. **Signal chain:** Use consecutive mains A → B → C, with the contact before A and destination C. A waypoint between A and B or exactly at B must not clear B. A waypoint continuing beyond B must include both A and B as separate secured subroutes. The contact must reject selecting B while skipping A. After a waypoint ends, a new assignment needs a fresh trigger or a manual request. Occupancy and conflicting movements must still prevent clearance.

For a failure, start with the test number, action, expected and actual result, and mod version. Include an image for display issues or the exact automation status message for rejected requests. Starting a new save is not a general repair step.
