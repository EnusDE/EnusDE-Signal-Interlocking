FILE NAME
EnusDE Signal and Interlocking - Early Alpha (0.7.40)

DESCRIPTION
Early alpha for Railroader 0.6.2. Signals, interlocking panels, train/shunting routes, GFM detection and initial automation. English/German. Use a test save; all players need the same version. Tutorial/user guide: work in progress.
