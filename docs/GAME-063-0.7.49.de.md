# 0.7.49-P0 – Vorbereitete Kompatibilitätstestfassung für Railroader 0.6.3

**Noch nicht gegen die Originalbibliotheken von 0.6.3 gebaut oder im Spiel geprüft.**
Der laufende Arbeitsbereich enthält weiterhin die bisherigen Bibliotheken. Diese
Datei ist deshalb ein ausdrücklich unbestätigter Testkandidat, keine bestätigte
0.6.3-Freigabe. Der ZIP-Abruf der neu hochgeladenen Bibliotheken scheitert hier am
Schreibschutz. Die aktualisierte Umgebung aus dem Screenshot ist im laufenden
Arbeitsbereich noch nicht enthalten.

## Änderungen

- Modversion 0.7.49; Spielabhängigkeit ausdrücklich `rr/game ==0.6.3`.
- Die bisher direkt referenzierte API `Game.UserPaths` wird beim Start aufgelöst.
  Bevorzugt wird `Game.HomeDirectory.UserPaths`, zusätzlich wird die Schreibweise
  eines verschachtelten Typs unterstützt. Nur wenn die neue API fehlt, wird die
  bisherige Variante verwendet.
- Der von Railroader gelieferte Pfad wird unverändert gelesen. Es werden keine
  Spielstände, Einstellungen oder Benutzerdaten verschoben.
- Ungültige Signaturen, leere Pfade oder ein fehlerhafter Getter werden gemeldet;
  es wird kein Ersatzpfad erraten.
- Enthält die Editor- und Zugnummernänderungen aus 0.7.48/0.7.47.

## Prüfstand

Die vorhandene vollständige Testsuite wird mit den tatsächlich verfügbaren
bisherigen Bibliotheken ausgeführt. Die neue Pfadvariante wird zusätzlich durch
gezielte simulierte API-Verträge geprüft. Diese Prüfungen belegen den Adapter und
bestehende Modlogik, ersetzen aber keinen Build mit den Original-DLLs von 0.6.3.

Vor einer Veröffentlichung bleiben erforderlich: gegen die neuen Managed-DLLs
bauen, native Hook-/Signaturprüfungen erneut ausführen und im Spiel sowie im
Mehrspieler testen. Alle Teilnehmer benötigen dieselbe Modversion 0.7.49.

## Manueller Spieltest des Kandidaten

Eine gesicherte Testwelt unter 0.6.3 verwenden. Mod aktivieren, Spielwelt laden,
IXL/STW und den Editor öffnen, Signal-/Weichen-/GFM-Rückmeldungen prüfen und eine
Fahrstraße stellen/auflösen. Wenn der optionale Übersetzungsmod vorhanden ist,
auch dessen Einheitenübernahme prüfen. Das Log auf fehlende Typen, Methoden und
Hook-Signaturen kontrollieren. Bei Fehlern die bisherige Anlage nicht überschreiben.

Ältere Pakete einschließlich 0.7.48 bleiben unverändert. Im ZIP befinden sich nur
die eigene Mod-DLL und Moddateien; keine Spielbibliotheken.
