# Vollbild und Bedienzuständigkeit

Öffne **STW → Stellwerk**. Die Tafel füllt die Spielfläche. **Bearbeiten** erscheint beim Host und wechselt auf derselben Tafel in den Editor. **Minimieren** erhält die Sitzung. Öffne **Stellwerk** erneut, um fortzufahren. **Modus beenden** gibt die übernommenen Bereiche an die konfigurierte Automatik zurück. Festgelegte Fahrstraßen laufen regulär weiter.

Unter **Bedienzuständigkeit** kannst du beobachten, in Bereitschaft auf wartende Anfragen schauen, Rangieren übernehmen oder alle Fahrarten eines Bereichs übernehmen. Die Bereichswahl verwendet die im Editor benannten Bereiche. Die Teilübernahme sperrt neue automatische Anfragen derselben Fahrart an den zugeordneten Startsignalen.

Im ESTW-Editor führen **Freie Strecke / GWB → Zwei Signale verbinden** zur Auswahl der Ausfahrt und Einfahrt. Prüfe den erkannten Fahrweg. Ergänze für GWB die Gegenrichtung. Aktive Anbindungen erscheinen als gestrichelte Linien zwischen den angeordneten Modulen. Die Linien zeigen die Zuordnung. Streckenerlaubnis, Freimeldung und Fahrstraßen werden weiter am Gleis geprüft.

Unter **Nummernanzeige** wechselst du zwischen Zugnummer und Fahrzeugkennung. Für einen erkannten Verband wird die Zugnummer der zugewiesenen Crew aus dem aktiven Railroader-Fahrplan gelesen. Eine vorhandene Feldnummer wird bei verifizierter Ausfahrt auf den Zugverband übernommen, sobald die Strecke oder der Folgebereich kein direktes Zugnummern-Zielfeld hat. Die Anzeige folgt den zugeordneten Gleisfreimeldeabschnitten.

## English

Open **IXL → Interlocking** for the fullscreen diagram. The host can switch to **Edit** in the same view. **Minimize** retains the takeover and current workspace. **End mode** hands back the selected areas to configured automation. Existing routes stay under normal interlocking supervision.

The host can observe, review pending requests in standby, take over shunting, or take over all movements in a named area. Use **Open line / GWB → Connect two signals** in the master interlocking editor. Review the detected path and add the opposite direction for bidirectional working. Dashed lines indicate the links between placed modules.

**Number display** switches between operational train numbers and locomotive identification. A confirmed train crew assignment supplies the active native timetable number. Verified departures can transfer a saved field number to the train so the number can follow occupancy onto the open line.
